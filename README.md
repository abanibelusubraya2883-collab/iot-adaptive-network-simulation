# Hybrid Adaptive Model for Low-Bandwidth Wireless Networks

## Overview
This project simulates IoT network performance using MATLAB and Simulink.

## Features
- Static vs Adaptive model comparison
- Protocol simulation: LoRaWAN, Zigbee, NB-IoT
- Performance metrics: Energy, Latency, Throughput, PDR

## Technologies
- MATLAB
- Simulink

## How to Run
1. Open MATLAB
2. Load the .slx file
3. Run simulation
